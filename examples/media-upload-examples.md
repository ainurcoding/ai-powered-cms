# 📸 Media Upload - Examples & Testing Guide

Complete guide untuk testing media upload dengan Cloudinary.

---

## 🔑 Prerequisites

### 1. Cloudinary Account Setup ✅

Pastikan sudah:
- ✅ Create account di https://cloudinary.com
- ✅ Get API credentials (Cloud Name, API Key, API Secret)
- ✅ Update `.env` file dengan credentials
- ✅ Restart server (`pnpm dev`)

### 2. Authentication ✅

Login dulu untuk get token:
```
POST http://localhost:8000/auth/login

Body:
{
  "username": "admin",
  "password": "password123"
}

Response: Save token dari result.token
```

## 📤 Upload File - Postman Setup

### **Endpoint:**
```
POST http://localhost:8000/media/upload
```

### **Authorization:**
```
Type: Bearer Token
Token: {{token}}
```

### **Body Setup (IMPORTANT!):**

1. **Select:** `form-data` (NOT raw JSON!)
2. **Add Fields:**

| Key | Type | Value | Required |
|-----|------|-------|----------|
| `file` | **File** | [Select image from computer] | ✅ Yes |
| `folder` | Text | `posts` | ⬜ Optional |
| `alt` | Text | `My image description` | ⬜ Optional |
| `caption` | Text | `Image caption` | ⬜ Optional |

**Screenshot Guide:**
```
Body Tab → 
  ○ none
  ○ form-data  ← SELECT THIS!
  ○ x-www-form-urlencoded
  ○ raw
  ○ binary

Then add:
Key: file      | Type: File | Value: [Choose Files button]
Key: folder    | Type: Text | Value: posts
Key: alt       | Type: Text | Value: Featured image for blog post
```

## 📋 List Media Files

### **GET /media**

**URL:**
```
GET http://localhost:8000/media?page=1&limit=10&folder=posts
```

**Auth:** Required

**Query Parameters:**
- `page=1` - Page number
- `limit=10` - Items per page
- `folder=posts` - Filter by folder
- `type=image` - Filter by type
- `search=sunset` - Search in filename/alt
- `sortBy=created_at` - Sort field
- `sortOrder=desc` - Sort direction

**Expected Response:**
```json
{
  "message": "Media files retrieved successfully",
  "result": [
    {
      "id": "uuid",
      "file_name": "sunset.jpg",
      "url": "https://...",
      "thumbnail_url": "https://...",
      "folder": "posts",
      "uploader": {
        "id": "uuid",
        "name": "Administrator"
      },
      "created_at": "2025-10-22T..."
    }
  ],
  "meta": {
    "page": 1,
    "limit": 10,
    "total": 5,
    "totalPages": 1,
    "hasNextPage": false,
    "hasPrevPage": false
  }
}
```

| Action | Owner | Admin | Other Users |
|--------|-------|-------|-------------|

## 🎨 Frontend Integration Example

### React Component:
```typescript
const MediaUploader = () => {
  const handleUpload = async (file: File) => {
    const formData = new FormData();
    formData.append('file', file);
    formData.append('folder', 'posts');
    formData.append('alt', 'Image description');

    const response = await fetch('http://localhost:8000/media/upload', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${token}`
      },
      body: formData
    });

    const data = await response.json();
    return data.result.url; // Cloudinary URL
  };
};
```

## 📊 Response Fields Explained

### **Upload Response:**
```json
{
  "url": "http://...",           // HTTP URL
  "secureUrl": "https://...",    // HTTPS URL (use this!)
  "thumbnailUrl": "https://...", // Auto-generated 200x200 thumbnail
  "publicId": "ai-cms/posts/...", // Cloudinary identifier (for delete)
  "width": 1920,                 // Original width
  "height": 1080,                // Original height
  "format": "jpg",               // File format
  "fileSize": 245678,            // Size in bytes
  "folder": "posts"              // Organization folder
}
```
